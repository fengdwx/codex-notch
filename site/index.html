02 / INSTALL

One minute, three steps, done.

No Swift, no Xcode, no build step. Download it and it just runs.

  1. 1

    Download and drag

    Grab the DMG (or ZIP) from GitHub Releases and drop CodexNotch into Applications.

  2. 2

    Use Codex once

    Sign in to ChatGPT and run Codex a single time — that's all it needs to read your local state.

  3. 3

    Open it

    First launch: click Open Anyway under Privacy & Security. No notch? It quietly falls back to the menu bar.

Reads the default ~/.codex directory. Keep Codex somewhere else? Set CODEX_HOME before you launch.
