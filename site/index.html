02 / INSTALL

Up and running in three steps.

No Swift, Swift Package Manager, or Xcode required. Just download and go.

  1. 1

    Download and open

    Grab the DMG (or ZIP) from GitHub Releases and drag CodexNotch into Applications.

  2. 2

    Sign in to Codex once

    Sign in to ChatGPT and use Codex once so the local login state exists.

  3. 3

    Launch CodexNotch

    On first launch, choose Open Anyway in Privacy & Security. Macs without a notch use a menu-bar fallback.

CodexNotch reads the default ~/.codex directory. If Codex uses another location, set CODEX_HOME before launching.
