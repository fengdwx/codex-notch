# CodexNotch 0.2.3

- **Recent tasks across days**: Recent conversations no longer disappear after 24 hours. Your selected count (0–5) applies to the latest available conversations, including after several days away or an app restart.
- **Efficient history loading**: Stops reading older logs once enough recent conversations have been found. Running tasks still take priority, and abandoned tasks are not revived.
- **Custom text editing**: Spaces at the end of a floating-bar signature are now visible immediately while typing.

Users on 0.2.1 or later can update through Settings → Check for Updates. Users on 0.2.0 or earlier should install this version manually. Existing preferences are preserved.

DMG and ZIP downloads are available for Apple Silicon on macOS 14 or later. The app has not been notarized by Apple. See the [installation guide](https://github.com/fengdwx/codex-notch/blob/v0.2.3/README.md#install).
