# CodexNotch 0.2.4 Preview

- **Notch height:** Compact wings now follow the display's measured camera area instead of a fixed 28–32pt range. Both indicator lanes use the same measured height.

This preview is available as a manual download. Settings → Check for Updates continues to use the stable release channel. Existing preferences are preserved.

DMG and ZIP downloads are available for Apple Silicon on macOS 14 or later. The app has not been notarized by Apple. See the [installation guide](https://github.com/fengdwx/codex-notch/blob/v0.2.4/README.md#install).
