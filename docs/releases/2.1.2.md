# CodexNotch 2.1.2

CodexNotch 2.1.2 updates the account switcher drawer to show live second-level reset countdowns with unified, restrained typography.

- **Live account reset countdowns:** Replaces static reset clock times and dates in the expanded notch account switcher with live second-level countdowns (`HH:mm:ss` and `Xd HH:mm:ss`), keeping monospaced digits aligned across rows.
- **Unstarted 5h window cue and semantic hierarchy:** Displays `5h Ready` (`5h 待开始`) alongside the `7d` countdown when a 5-hour window is still at 100%, uses a calm uniform secondary tone for healthy windows, highlights low/exhausted windows (≤ 20%) in soft amber, and marks elapsed reset windows in green.

Update from Settings → Check Updates, or download the DMG or ZIP. Existing preferences and saved accounts are preserved.

Downloads are available for Apple Silicon on macOS 14 or later. The app has not been notarized by Apple. See the [installation guide](https://github.com/fengdwx/codex-notch/blob/v2.1.2/README.md#install).
