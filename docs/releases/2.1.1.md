# CodexNotch 2.1.1

CodexNotch 2.1.1 fixes quota and active-account mismatches when `~/.codex/auth.json` is updated outside CodexNotch.

- **Automatic `auth.json` reconciliation:** Reconciles the active account badge at startup and during runtime whenever `~/.codex/auth.json` changes externally (such as via `codex login` or another account switcher), and detects file changes promptly without waiting for the next 60-second poll.
- **Live session drift detection:** Reads live `rate_limits` updates from active Codex rollout logs so that if `auth.json` changes while Codex is still running under another account, the notch continues showing the running session's real-time remaining quota, disables reset-credit actions against mismatched credentials, and displays an amber restart notice until Codex relaunches or accounts match again.

Update from Settings → Check Updates, or download the DMG or ZIP. Existing preferences and saved accounts are preserved.

Downloads are available for Apple Silicon on macOS 14 or later. The app has not been notarized by Apple. See the [installation guide](https://github.com/fengdwx/codex-notch/blob/v2.1.1/README.md#install).
