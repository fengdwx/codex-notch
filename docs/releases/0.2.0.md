# CodexNotch 0.2.0

这次更新聚焦刘海的日常体验：展开收回更连贯，文字更清爽，中间区域支持自定义。

## 更新内容

- **展开与收回**：悬停时轻微预撑，展开到位后柔和回弹，收回过渡更连贯，并加入淡阴影。
- **字体与排版**：调整字体层级和留白，文字在过渡中保持自然大小，减少缩放造成的视觉跳动。
- **浮动条自定义**：支持个人签名、轨道签名、运行计时和细流光四种中间样式；签名最多 12 个字符，持续流光覆盖运行、完成和空闲状态，取消签名前的状态点。
- **图标与任务标题**：调整浮动条状态图标的视觉平衡；优先显示 Codex 最新任务名称，过滤附件说明，修正转义字符显示。

设置即时生效并保存在本机。关闭动画或启用系统 Reduce Motion 后，保留清楚的静态状态提示。

## 下载与安装

- 适用于 Apple Silicon（arm64）、macOS 14 及以上版本。
- 提供 DMG、ZIP 和各自的 SHA-256 校验文件。
- 已安装的用户可在设置中点击“检查更新”，打开 GitHub 下载页后手动安装。
- 应用使用 ad-hoc 签名，尚未经过 Apple 公证；DMG 不会消除 macOS 首次运行提示。安装步骤见 [中文 README](https://github.com/fengdwx/codex-notch/blob/v0.2.0/README.zh-CN.md#立即安装)。
