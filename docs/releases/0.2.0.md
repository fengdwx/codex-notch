# CodexNotch 0.2.0

This update improves the everyday notch experience with smoother expansion and collapse, cleaner text, and a customizable center area.

## What's new

- **Expansion and collapse**: Gentle hover feedback, a soft rebound as the card opens, smoother collapse, and a subtle shadow.
- **Typography and spacing**: Clearer text hierarchy and more breathing room. Text stays at its natural size during transitions to reduce visual jumping.
- **Floating bar customization**: Four center styles: personal signature, orbit, elapsed time, and light flow. Signatures support up to 12 characters and shimmer continuously during running, completed, and idle states. The preceding status dot has been removed.
- **Icons and task titles**: Better-balanced floating bar status icons. Conversation labels use the latest Codex task names, filter attachment headers, and display escaped characters correctly.

Settings apply immediately and are saved locally. Turning off animations or enabling Reduce Motion preserves clear static status indicators.

## Download and install

- Requires Apple Silicon (arm64) and macOS 14 or later.
- DMG, ZIP, and their SHA-256 checksum files are provided.
- Existing users can click Check for Updates in Settings to open the GitHub download page and install this version manually.
- The app uses an ad-hoc signature and has not been notarized by Apple. The DMG does not eliminate the first-launch macOS security prompt. See the [installation guide](https://github.com/fengdwx/codex-notch/blob/v0.2.0/README.md#install).
