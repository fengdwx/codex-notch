# CodexNotch 0.2.1

- **设置窗口**：已打开设置时，再次点击设置会将窗口带到前面。
- **应用内更新**：点击“检查更新”后，可直接下载、校验、安装新版并重启，无需跳转下载页。

从 0.2.0 或更早版本升级时，需要先手动安装一次 0.2.1；之后可在设置中直接更新，现有设置会保留。

适用于 Apple Silicon、macOS 14 及以上版本，提供 DMG 和 ZIP。应用尚未经过 Apple 公证，DMG 不会消除首次运行提示；安装方法见[中文 README](https://github.com/fengdwx/codex-notch/blob/v0.2.1/README.zh-CN.md#立即安装)。
